Pre-release. The 0.1 core runtime is being built now. Nothing is on PyPI yet.

Python 3.11+ · zero runtime dependencies · ships py.typed · MIT

Localization for Python, kept in plain JSON.

locjson reads one JSON file per locale and answers t("key") from it. Lookups walk a fallback chain you can predict, {name} placeholders can't reach into your objects, and plurals get an explicit zero.

pip install locjson works once 0.1.0 is published. Until then, the API on this page is the planned 0.1 surface and can still change.

One key, four catalogs

l10n.t("greeting", locale=…, name="İlkay")
  • enHello, İlkay!
  • trMerhaba, İlkay!
  • zh-Hant你好，İlkay！
  • ar · direction("ar") == "rtl"مرحبًا، İlkay!

Catalogs are read as UTF-8 on every OS, with or without a BOM, so Turkish İ and ı come back exactly as written. An Arabic catalog can declare its own direction in $meta.

    §2
    
    
    Five rules the runtime keeps
    
    
    Errors in your files show up at load time, with a location. Slips while rendering stay quiet unless you ask for strict mode.
    
  
    

  
      
    
    1. 
      2.1
      
      
        
      Placeholders are names, nothing else
      
        
      Templates are compiled once, when the catalog loads. A placeholder is a plain {name} and doubled braces are literal. Attribute access, indexing, format specs and conversions are rejected before your app renders anything.
      
        
      Format values in Python first: t("total", price=f"{price:.2f}").
      
      
      
      
      
        
      
          
      templateat load
      
          
            
      "Hello, {name}!"compiled
      
            
      "Use {{name}}"renders Use {name}
      
            
      "{0}"rejected
      
            
      "{user.name}"rejected
      
            
      "{items[0]}"rejected
      
            
      "{price:.2f}"rejected
      
            
      "{value!r}"rejected
      
                
        
      
      
      
    
      2. 

    
    2. 
      2.2
      
      
        
      Broken files fail at load, with a location
      
        
      Numbers, booleans or arrays as values, duplicate keys, NaN and key-path collisions raise InvalidCatalogError when the catalog is loaded. The error exposes .path and .pointer, an RFC 6901 JSON pointer to the bad value.
      
      
      
      
      
        
      locales/tr.jsonrejected
      

      {
  "inbox": {
    "messages": {
      "one": 1,
      "other": "{count} mesajınız var"
    }
  }
}
      
        
      InvalidCatalogError → /inbox/messages/one
      
      
      
    
      3. 

    
    3. 
      2.3
      
      
        
      Slips at render time stay quiet, unless you ask
      
        
      A key missing from the whole chain or a variable you forgot to pass never takes a page down by default. A missing variable stays as literal {name} text. Each slip is logged at DEBUG on the locjson logger.
      
        
      Use missing="raise" in tests and every slip becomes an exception.
      
      
      
      
      
        
      
          
      missing=t("nav.profile") gives
      
          
            
      "key"'nav.profile' (default)
      
            
      "empty"''
      
            
      "raise"MissingTranslationError, a LookupError
      
            
      callablewhatever fn(key, locale) returns
      
                
        
      
      
      
    
      4. 

    
    4. 
      2.4
      
      
        
      The current locale belongs to the request
      
        
      Each Localizer keeps its current locale in a ContextVar. Every asyncio task and thread sees its own value, so two requests in two languages don't step on each other.
      
      
      
      
      

      with l10n.use("tr"):         # restored on exit
    l10n.t("nav.home")       # 'Ana sayfa'

l10n.set_locale("tr")        # this context only
l10n.current_locale          # 'tr'

l10n.negotiate("tr-TR,tr;q=0.9,en;q=0.8")  # 'tr'
l10n.direction("ar")                       # 'rtl'
      
      
      
    
      5. 

    
    5. 
      2.5
      
      
        
      Nothing to install but locjson
      
        
      No runtime dependencies. The package ships py.typed and is checked with mypy --strict. Catalogs load lazily per locale and are compiled once, so a warm t() is a dict lookup plus a join, with no file I/O.
      
        
      Catalogs can come from anywhere that implements the Loader protocol. DictLoader keeps them in memory, which is handy in tests.
      
      
      
      
      

      from locjson import DictLoader, Localizer

l10n = Localizer(
    loader=DictLoader({"en": {"greeting": "Hello, {name}!"}}),
    default_locale="en",
)
l10n.reload()  # rebuild; broken files keep the old set
